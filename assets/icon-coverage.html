这条核查说明什么

1,600 和 6,200 的差别，对我们是没差别的。 这个应用满打满算需要 84 个形状：83 个有专用图标，1 个只能退到备选，0 个完全找不到。 真正的风险不是"库太小"，而是"我们要的那个具体形状没有" —— 黄色那几行就是。
库里确实覆盖不到的两类（这类换库也解决不了）：
① 后缀级文件图标 —— .docx / .xlsx / .psd / .fig / .7z 各要一张脸。 Lucide 只给"文本 / 代码 / 表格 / 图片"这类按大类的图标，不分后缀。 要做成 VS Code 那样一后缀一图标，得另配一套（material-icon-theme，彩色 32 格）—— 但那跟"绿只做强调"的配色语言冲突，所以我建议按大类，不做到后缀级。
② 品牌图标 —— GitHub / 微信 / 各类云盘。Lucide 明确不收品牌 logo（法律与维护成本）。 真要接 Git 面板，另加 simple-icons（CC0），只在那一处用。
能自定义图标吗？ 能 —— 现在任何一个没用上的 lucide 图标、 或者你自己画一个 16 格的 SVG，都能塞进 FOLDER_OVERRIDES。 图标库是"默认值"，不是"上限"。
