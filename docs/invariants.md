# 不变量

每条都是"违反了会丢数据或会撒谎"的东西。**守它的测试**一栏是硬要求：
新增一条不变量，就得同时加一条能把它钉死的测试。

状态：`✅` 已有测试 · `⬜` 待建

## 路径与文件

| # | 不变量 | 为什么 | 守它的测试 |
|---|---|---|---|
| 1 | 绝对路径与越界 `..` **抛错**，不悄悄夹紧 | 夹紧会把"写错路径"变成"写到别处" | ✅ `tests/unit/path.test.ts` |
| 2 | 路径在这一层归一（反斜杠 → `/`），上层只当不透明串用 | 反斜杠只该踩一次 | ✅ `tests/unit/path.test.ts` |
| 3 | 后缀判定 `dot > 0`（`.gitignore` 不算有后缀） | `extOf` 与 `stemOf` 必须同一套判定，否则改名会吃掉点开头文件 | ✅ `tests/unit/path.test.ts` |

| 5 | **重名绝不覆盖**，撞了加 `-2` / `-3` | 覆盖一次就是丢一篇 | ⬜ `tests/unit/filename.test.ts` |

| 5b | 宿主层拒收绝对路径 / 盘符 / 反斜杠 / `..` | 前端拿不到、也造不出仓库外的路径；沙箱因此是天然的 | ✅ `src-tauri/src/bin/pathcheck.rs` |

## 反向清单：这些**不算**问题

写下来是为了防止有人"顺手修好"：

- **反链 / 标签 / 全文索引丢了** —— 那是缓存，重扫一遍即可，不算丢数据
- **`.dusk/` 目录被删了** —— 全量重读一遍即可，不算丢数据
- **两个同名文件在不同目录** —— 合法，`[[名字]]` 按"同目录优先"解析
